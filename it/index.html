Italy · Chamber of Deputies · 25 September 2022

Italy's published count for the Chamber of Deputies.

The Chamber of Deputies is the lower house of parliament. Its file reports each list by circoscrizione, which is a group of seats. The outline file used here draws five areas, not the 20 regions, so each area on this map adds the circoscrizioni inside it.

The number shown for a list is the figure the Chamber prints for that circoscrizione. It is the list's valid votes plus the votes the Chamber assigns to the list there, and those figures add up to the valid ballots. A coalition column in the same file repeats its lists, so it is not counted again. Nord-Ovest adds Piemonte, Liguria, and Lombardia. Valle d'Aosta is not a row in this list-vote file, so it is not included. A mark means one list's figure is larger than the others. Abbreviations such as FDI, LEGA, FI, PD-IDP, and M5S are printed that way in the file. Candidate-name files are not used.

The five areas

The outline file draws Nord-Ovest, Nord-Est, Centro, Sud, and Isole. It does not draw the 20 regions separately. Each area adds the circoscrizioni in the Chamber's one national file. The number for a list is the Chamber's circoscrizione figure: the list's valid votes plus the votes assigned to that list there. A coalition total in the file is the sum of its lists and is not added again. Valle d'Aosta is not a row in that file.
