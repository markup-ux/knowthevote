Spain's published count for Congress.

Congress is the lower house of parliament. The ministry's file lists each province. This map adds those province columns into the autonomous community they belong to. Ceuta and Melilla stay as their own outlines.

A mark means one list has more votes than the others. The file has no color code, so the color is only there to tell the lists apart. The seat columns in the same file are not used.

The autonomous communities

An autonomous community is one of Spain's main regions. Ceuta and Melilla are the two autonomous cities and each has its own outline. The number adds the ministry's province columns. It is the Congress vote, not a count of seats.

Leaders.vote is an independent voter guide. It is not a campaign, not an endorsement, and not a site of any election authority. This page is Spain.

Vote totals are copied from the Interior Ministry Congress file. The file lists provinces. This map adds each province into its autonomous community for the Congress election of 23 July 2023. A community is colored only from those reported votes. This site does not declare a result. It does not ask for a home address, a phone number, or an email address.
